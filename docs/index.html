访问令牌（PAT）

数据保存在私有仓库 XPHcsc/code-vault-data 的 codevault.json。 令牌只需 Contents: 读写 权限，仅存于当前浏览器，不会写入网站代码。

没有令牌？到 github.com/settings/personal-access-tokens/new 创建 Fine-grained token，仅授权 code-vault-data 仓库，权限勾选 Contents: Read and write。

手动同步

日常增删改会自动同步。当多设备修改冲突时使用以上按钮手动处理，操作前建议先导出备份。

断开连接
